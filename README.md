# JustScript
JustScript 0.6.0 — скриптовый редактор для JustMC Creative+

Клиентский Fabric-мод для Minecraft 1.21.11.

ЧТО УМЕЕТ

• Единое меню (J): карточки «Глобальные скрипты», «Модули», «Настройки» и дерево проекта с прокруткой колесом.

• Три языка: JustMC JSON, Xero и JMCC. Язык выбирается для каждого скрипта.

• Редактор: подсветка, номера строк, выделение мышью, перетаскивание строк красным кружком, подсветка парных скобок по Shift.

• Отмена/повтор, поиск с заменой, переход к строке: Ctrl+Z, Ctrl+Shift+Z, Ctrl+F, Ctrl+H, Ctrl+G.

• История: до 100 копий на скрипт, просмотр и откат к любой копии.

• ИИ-помощник в редакторе: бесплатное облако, свой OpenAI-совместимый сервер или локальная Ollama; знает язык и вид скрипта, умеет вставить код или заменить весь скрипт.

СОБЫТИЯ И СКРИПТЫ

• Функции и процессы — только в глобальном скрипте. Если в обработчике больше 60 действий, мод сам выносит их в функцию.

• Порядок скриптов настраивается; глобальный скрипт всегда идёт первым.

• «Значения {}» — справочник типов JustMC с готовыми шаблонами вставки.

ВАЖНЫЕ КОМБИНАЦИИ

• J — меню мода.
• Ctrl+ПКМ по блоку/сущности/игроку — код-меню объекта (работает в креативе).
• Ctrl+S — сохранить, Ctrl+Enter — собрать JSON в буфер.
• Ctrl+Z / Ctrl+Shift+Z — отмена / повтор.
• Ctrl+F / Ctrl+H / Ctrl+G — поиск / замена / переход к строке.
• Ctrl+Shift+K — удалить строку или выделение.
• Ctrl+D — дублировать скрипт в дереве.
• Tab — принять подсказку или поставить отступ.
• Shift — подсветить парную скобку {} [] ().
• Shift+клик — выделить диапазон, Delete — удалить выделенные.

ВКЛАДКА «ПОМОЩЬ»

Внизу главного меню есть кнопка «Помощь». Внутри:
• все клавиши мода, редактора, меню и основные клавиши игры — с текущими значениями, включая переназначенные;
• короткие советы по редактору;
• кнопка «Сменить клавиши…» — сразу открывает ванильные бинды (Управление → Назначение клавиш → JustScript).
